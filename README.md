# Telegram-бот для пары «Мы»

MVP-версия бота, который:
- создаёт пару по коду;
- соединяет двух пользователей;
- случайно выбирает вопросы;
- собирает ответ;
- отправляет ответ партнёру;
- сохраняет историю ответов в SQLite.

## 1. Создайте бота в Telegram

Откройте @BotFather, выполните /newbot, задайте имя и username и получите BOT TOKEN.

Никому не отправляйте токен.

## 2. Установка

Нужен Python 3.11+.

```bash
python -m venv .venv
```

Windows:
```bash
.venv\Scripts\activate
```

macOS/Linux:
```bash
source .venv/bin/activate
```

```bash
pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и вставьте токен:

```env
BOT_TOKEN=ваш_токен
```

## 3. Запуск

```bash
python bot.py
```

Пока программа запущена, бот работает.

## 4. Как протестировать

1. Откройте бота с первого Telegram-аккаунта и нажмите /start.
2. Нажмите «Моя пара» → «Создать пару».
3. Откройте бота со второго аккаунта и нажмите /start.
4. Нажмите «Моя пара» → «Ввести код партнёра».
5. Введите код.
6. Нажмите «Случайный вопрос».
7. Ответьте.
8. Ответ должен прийти второму пользователю.

## Важно

Telegram-бот не может первым написать пользователю, который ещё не начал диалог с ботом. Поэтому оба партнёра должны хотя бы один раз открыть бота и нажать /start.

## Дальнейшее развитие

Следующий этап можно расширить:
- ежедневные вопросы по расписанию;
- 300–1000 вопросов;
- категории и уровни близости;
- «ответить взаимно» — оба отвечают на один вопрос;
- отложенная доставка;
- история пары;
- статистика;
- анонимные вопросы;
- фото/голосовые ответы;
- подписка/платные функции;
- веб-панель администратора;
- PostgreSQL вместо SQLite для постоянного хостинга.
